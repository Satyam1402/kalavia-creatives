Put your image files here:

1. logo.png   -> square logo (e.g. 512x512). Header + favicon/icons.
                 Until added, a gradient "K" shows automatically.

2. og.jpg     -> 1200 x 630 pixels. Used for the WhatsApp/Instagram link
                 preview when the site is shared. YOU MUST SUPPLY THIS.

3. samples/   -> optional real portfolio images (e.g. samples/1.jpg).
                 To use one, set its path in data/site.js under
                 portfolio.items[].image (e.g. image: "/samples/1.jpg").
                 Until then, polished CSS mockup posters are shown.
